# 3D-island
一个用 GPT 辅助搭建的微缩 3D 小岛，也是我作为文科生的第一次 vibe coding 练习。  最初想做一个展示自己的作品集网站，于是先搭了一栋被绿植围绕的小洋房：推门进去，可以在房间里走动，翻翻日记、看看相框，也可以去花房待一会儿。作品还在慢慢积累，小岛就先作为它们未来的住所。  可以体验什么  小岛与小屋：加载动画、推门进入、微缩视角与自由走动。  卧室探索：点击香水、旋转八音盒和可翻页的日记。  书房画廊：点击墙上相框，浏览六张 AI 角色立绘，支持切换与放大。  厨房与花房：探索不同房间，看看郁金香、芍药和窗外的树木。  手机操作：使用屏幕箭头移动，拖动画面转向。
